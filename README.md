IRON NEST: HEAVY TURRET CALCULATOR

Interactive command-line calculator designed to compute precise artillery firing solutions, turret rotations, elevations, and powder charge options while tracking safety limits.

## Features
- **Dynamic Calculation:** Automatically calculates elevation based on distance and powder charges.
- **Powder Flexibility:** Provide a specific powder charge (1x–6x) for a direct solution, or leave it blank to view all possible powder options at a glance.
- **Safety Checks:** Automatically flags whether an elevation safely clears mechanical limits (e.g., the 60° elevation ceiling).
- **Direction Mapping:** Converts degree rotations into clear cardinal/intercardinal direction labels (e.g., North, Southeast, South).
- **Clean Formatting:** Uniform padding for easy reading at a glance.
- **Interactive Session:** Run continuously in a single window until you choose to exit.

## How to Use

1. Make sure you have **Python 3** installed.
2. Run the script:
   ```bash
   python IronNestHeavyTurretCalculator.py
3. Input Bearings, Distance, Powder Charges (<- This is optional, two args to show all possible elevation).
4. Aim and fire at will!
